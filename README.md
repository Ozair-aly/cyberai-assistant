🛡️ Cybersecurity AI Assistant

An AI-powered chatbot built with Python, Streamlit, LangChain, and Groq Llama 3.1 that answers cybersecurity-related questions and provides educational guidance on security concepts.

🚀 Features

* 🤖 AI-powered cybersecurity chatbot
* 🔒 Answers only cybersecurity-related questions
* 🌐 Covers multiple cybersecurity domains
* ⚡ Fast responses using Groq Llama 3.1
* 🎨 Clean Streamlit user interface
* 🛡️ Beginner-friendly educational assistant

📚 Topics Covered

* Network Security
* Malware Detection
* Phishing Awareness
* Password Security
* Web Security
